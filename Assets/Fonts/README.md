# Fluent System Icons

Original Regular and Filled font resources from the frozen Windows reference's
Wpf.Ui.dll. Microsoft Fluent System Icons, MIT licensed:
https://github.com/microsoft/fluentui-system-icons

License: https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE
The fonts are embedded in the Linux application so icons do not depend on
installed Windows fonts. No Segoe UI text font is redistributed.
